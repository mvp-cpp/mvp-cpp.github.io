MVP

MVP is a C++ toolkit for GWAS, population structure analysis, meta-analysis, high-dimensional phenotype analysis, and visualization. CPU parallelism and optional GPU acceleration enable efficient analysis of large genomic datasets.

01 / M — Memory-efficient

A smaller memory footprint for genomic analysis.

  • 01
    Memory-mapped access

    Access compact genotype data directly from disk through memory mapping, without loading the entire genotype dataset into RAM at once.

  • 02
    Block-wise genotype processing

    Process genotype data in blocks, limiting the amount of decoded data held in working memory.

  • 03
    Mixed-precision computation

    Use single- and double-precision computation to balance memory use and numerical precision.

03 / P — Parallel-accelerated

Match the workload to your hardware.

MVP uses multithreaded computing with high-performance math libraries (Intel MKL, Kunpeng [鲲鹏] KML, OpenBLAS, and Apple Accelerate) and OpenMP to accelerate the analysis of large genomic datasets.

An optional CUDA backend brings GPU acceleration to matrix operations and eigendecomposition, with multi-GPU eigendecomposition available on supported systems.
